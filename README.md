# 🍱 RasoiBox - Multi-Page Tiffin & Food Delivery Platform

A responsive, feature-rich multi-page web platform for **Daily Homely Tiffin Subscriptions & Instant Food Delivery**, built entirely with **pure HTML5, CSS3, and Vanilla JavaScript (ES6+)** with zero external frameworks or build dependencies.

---

## 📄 Dedicated Pages Overview

1. [**`index.html`**](file:///c:/Users/91939/Documents/Tiffin%20and%20Food%20Delivery%20Platform/index.html) — **Home Landing Page**
   - Hero banner with delivery slots & value badges
   - Today's Live Kitchen Thali showcase with live countdown timer
   - Quick overview of popular tiffin subscriptions and a la carte meals
   - How it works 4-step guide & subscriber reviews preview

2. [**`plans.html`**](file:///c:/Users/91939/Documents/Tiffin%20and%20Food%20Delivery%20Platform/plans.html) — **Tiffin Subscription Plans Page**
   - Complete meal plan catalog (Standard, Deluxe, Fitness, Non-Veg)
   - Interactive duration tabs (Single Trial, 7-Day Weekly, 30-Day Monthly)
   - Dietary filters (Pure Veg 🟢, Non-Veg 🔴, High Protein 🥗)
   - Subscription modal to select meal slot (Lunch, Dinner, Both) and start date

3. [**`menu.html`**](file:///c:/Users/91939/Documents/Tiffin%20and%20Food%20Delivery%20Platform/menu.html) — **A La Carte Menu & Quick Bites Page**
   - Instant 30-minute hot delivery catalog
   - Real-time search filter and category pills (Daily Specials, North Indian, South Indian, Healthy Bowls, Desserts)
   - Interactive quantity stepper directly on food cards

4. [**`cart.html`**](file:///c:/Users/91939/Documents/Tiffin%20and%20Food%20Delivery%20Platform/cart.html) — **Dedicated Cart & Checkout Page**
   - Detailed item review with +/- controls and remove action
   - Promo code input with instant discount calculation (`FIRSTTIFFIN`, `FREEDEL`, `DESI50`)
   - Full delivery form: Full Name, Phone, Address, Delivery Slot
   - Payment method selector: UPI / QR, Cards, Cash on Delivery
   - Seamless order placement linking directly to live order tracking

5. [**`track.html`**](file:///c:/Users/91939/Documents/Tiffin%20and%20Food%20Delivery%20Platform/track.html) — **Live Order Tracking Page**
   - Real-time 4-stage visual stepper (Order Confirmed → Simmering in Kitchen → Out for Delivery → Delivered)
   - Valet details card with direct call button
   - Summary of ordered items and delivery address

6. [**`about.html`**](file:///c:/Users/91939/Documents/Tiffin%20and%20Food%20Delivery%20Platform/about.html) — **About Us, Hygiene & FAQs Page**
   - The RasoiBox story and our 4 hygiene pillars (No dalda, ozone-washed veggies, no artificial food colors)
   - Customer testimonial cards
   - Expandable FAQ accordion
   - Corporate catering and bulk order inquiry section

## 🚀 How to Run the Website

Simply double-click [`index.html`](file:///c:/Users/91939/Documents/Tiffin%20and%20Food%20Delivery%20Platform/index.html) in your Windows File Explorer to open it in your browser. All navigation links smoothly switch between the dedicated pages while keeping your cart and active orders synchronized!
